# PaG Action Planner v0.1.0-alpha.1 — First Demo Preview

> Working title · Early alpha

This is the first public preview of the PaG Action Planner.

PaG is still at a very early stage. The purpose of this pre-release is to make the concept tangible, let interested people explore the current workflows, practise how the app behaves during an action, and collect early feedback.

## What you can try

- preparation of an action
- persons and pseudonyms
- planned roles
- tasks and priorities
- transition from preparation to an active action
- operational person status
- current functions
- the ACTIVE situation overview (`Lagebild`)

## PaG Demo

This pre-release is intended to include a separate **PaG Demo APK** with synthetic example data.

The demo uses a separate Android application ID and can be installed alongside the product app. Demo changes are non-persistent and the demo deliberately simplifies the security workflow of the product application.

**Do not enter real personal or operational data into the demo.**

## Important

This is experimental alpha software. Features, UI and internal formats may change without migration guarantees.

The project has not yet undergone an independent external security audit.

Known test limitation: the automated Galaxy/API33 demo UI probe at font scale 2 is not yet fully green for the hub. Large-font behavior remains under active testing.

Feedback about unclear workflows, missing functionality and usability is very welcome.
